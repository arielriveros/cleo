# Duskwell

A small 2D metroidvania on the flat 2D renderer: a warrior with a three-hit combo, bats that wake as you pass, two rooms the camera slides between, one-way platforms, checkpoints that save the game, diamonds, and the dash relic that carries you over the pit. Pixel-perfect at 480 x 270, with parallax backdrops and glowing torches.

A Cleo project folder: open it in the Cleo desktop app (Project ▸ Open Folder…), and what you change is what
git sees. See [examples/README.md](../README.md) for how the examples are kept: their binary data
(`npm run examples:fetch`), their tests (`npm test` here), and publishing a change.
