# Firing Line

A first-person shooter: walk, sprint, crouch, aim down sights, hip and aimed fire, reloads and three weapons against bots that search, take cover, retreat when hurt and call for reinforcements. One scene, one Game Manager with a game-type list (one against all, team deathmatch, free for all, co-op): put the manager and some fighters in any scene and it plays. Online too: co-op against a horde of bots, or eight against eight with bots in the empty seats (Play › Multiplayer).

A Cleo project folder: open it in the Cleo desktop app (Project ▸ Open Folder…), and what you change is what
git sees. See [examples/README.md](../README.md) for how the examples are kept: their binary data
(`npm run examples:fetch`), their tests (`npm test` here), and publishing a change.
